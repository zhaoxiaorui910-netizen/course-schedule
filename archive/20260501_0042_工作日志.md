# 课程表项目 - 工作日志

## 2026-04-29：角标功能引入的 rowspan 失效 bug

### 问题描述
给课表添加"角标"功能（标记同一时段存在非本周课程）后，所有课程卡片的高度都只有一行，
即使课程实际跨2小节（如第1-2节），也只显示在第1节的框里。

### 根因
新增 `SlotCourse` API 数据结构时，漏掉了 `start_period` 和 `end_period` 字段。
前端渲染函数 `render()` 中计算 `span` 时用了 `activeCourse.end_period`，
该值为 `undefined`，导致 `span = NaN`，`rowspan` 属性没设上去。

### 修复
前端的 `span` 计算改为使用 `slot.end_period - slot.start_period + 1`，
slot 对象本身一直携带正确的节次范围信息。

### 教训
- API 新增数据模型时，检查前端的所有消费方是否需要新字段
- 凡是涉及表格布局的属性（rowspan、colspan），值错误时会静默失败（不报错也不生效），排查时要优先检查
- 出现"看起来只渲染了一半"的布局问题，先检查渲染循环里关键变量的值
